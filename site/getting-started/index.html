Quick start

Run UniqTools in 60 seconds.

These commands show the intended workflow: profile the input, check schema drift, then produce a row-level diff artifact.

1. Install

pip install uniqdiff
# install UniqTools packages from this repository while packages are in preview

2. Create two sample CSV files

cat > old.csv <<'EOF'
id,status,score
1,active,10
2,active,20
EOF

cat > new.csv <<'EOF'
id,status,score,country
1,inactive,10,FR
3,active,30,FR
EOF

3. Run the workflow

uniqtools profile file old.csv --key id
uniqtools check schema old.csv new.csv --fail-on-schema-change
uniqtools rowdiff old.csv new.csv --key id --column status --output changes.jsonl

What you get

Profile JSON

Rows, file size, columns, empty counts, duplicate key preview, and invalid record counts.

Schema check

Added columns, removed columns, type changes, nullable changes, and CI exit codes.

Row diff JSONL

Changed fields for matched keys, plus added and removed row counts from uniqdiff.
