Open-source data workflow tools for Python teams

Data diff, profiling, and CI checks for CSV, TSV, and JSONL.

UniqTools helps data engineers and backend teams compare files, detect schema drift, profile datasets, and fail CI when data changes break expectations. It is built on the stable uniqdiff comparison engine.

Why UniqTools

Built for ETL reality

Compare exports, validate schemas, inspect duplicates, and generate row-level change artifacts without writing one-off scripts every time.

Engine plus tools

uniqdiff owns exact comparison semantics. UniqTools adds product-level workflows such as profiling, CI checks, row diff, and future reports.

Friendly to automation

Commands return JSON, support CI exit codes, and produce artifacts that can be loaded by scripts, dashboards, and AI agents.

Tools

uniqprofile

Profile CSV, TSV, and JSONL files before diff or validation.

uniqtools profile file users.csv --key id

uniqcheck

Run CI-friendly checks for required columns, duplicates, presence, and schema drift.

uniqtools check schema old.csv new.csv --fail-on-schema-change

uniqrowdiff

Find changed fields for rows that share the same key.

uniqtools rowdiff old.csv new.csv --key id --output changes.jsonl

uniqtools-cli

Use one command entrypoint for profile, check, and rowdiff workflows.

uniqtools --help

Use cases

Problem Command Best tool
Preview a file before an ETL job uniqtools profile file export.csv --key id uniqprofile
Fail CI when schema drift appears uniqtools check schema old.csv new.csv --fail-on-schema-change uniqcheck
Find field changes by primary key uniqtools rowdiff old.csv new.csv --key id uniqrowdiff
Detect added and removed rows uniqtools check compare old.csv new.csv --key id --fail-on-added uniqcheck plus uniqdiff
