Architecture

Engine boundary first.

UniqTools is intentionally layered. The uniqdiff package owns exact comparison semantics. UniqTools packages own user workflows.

What belongs in uniqdiff

  • exact comparison semantics;
  • key extraction and normalization;
  • memory and disk backends;
  • field diff and schema diff primitives;
  • JSONL event streams and lazy readers.

What belongs in UniqTools

  • file profiling and workflow preflight;
  • CI policies and exit codes;
  • row-level diff workflows;
  • future HTML/PDF/Excel reports;
  • future workflow orchestration and connectors.
