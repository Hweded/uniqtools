Tool

uniqprofile

Lightweight file profiling for data engineers who need to understand a CSV, TSV, or JSONL file before comparing it or loading it into a pipeline. 

uniqtools profile file users.csv --key id
uniqtools profile file events.jsonl --format jsonl --key event_id --sample-size 10000

Profile fields

  • file path, format, and size in bytes;
  • row or record count;
  • column or field names;
  • empty value counts per column;
  • duplicate key count and duplicate key sample;
  • invalid JSONL record count.

Best for

ETL preflight

Check file shape before a data pipeline runs.

CI diagnostics

Print compact JSON when a data check fails.

Dataset triage

Quickly inspect exports without opening pandas or a notebook.
