Tool

uniqtools-cli

A thin unified entrypoint for the UniqTools ecosystem. It delegates to package CLIs instead of duplicating business logic. 

uniqtools profile file users.csv --key id
uniqtools check compare old.csv new.csv --key id --fail-on-added
uniqtools rowdiff old.csv new.csv --key id --output changes.jsonl

Design

The direct commands remain available: uniqprofile, uniqcheck, and uniqrowdiff. The unified command exists for repeatable local workflows and CI scripts.
