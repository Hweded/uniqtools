Tool

uniqrowdiff

Row-level changed-field analysis for CSV files matched by key. The exact field comparison comes from uniqdiff 1.1; uniqrowdiff adds workflow policy, duplicate-key handling, output shaping, and CI exit codes. 

uniqtools rowdiff old.csv new.csv --key id --output changes.jsonl
uniqtools rowdiff old.csv new.csv --key id --column status --column score
uniqtools rowdiff old.csv new.csv --key id --sorted-input --max-rows 1000

Output

JSON summary is printed to stdout. Changed rows can be written as JSONL.

{
  "changed_rows": 1,
  "changed_fields": 2,
  "only_in_first": 3,
  "only_in_second": 4,
  "duplicates_first": 0,
  "duplicates_second": 0
}

Best for

  • finding changed fields in database exports;
  • reviewing ETL output changes before deployment;
  • producing machine-readable JSONL artifacts for reports;
  • checking whether key-matched rows changed in CI.
