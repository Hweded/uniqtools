Tool

uniqcheck

CI-friendly data checks built on top of the uniqdiff engine. Use it to fail builds when files contain duplicate keys, missing columns, row presence changes, or schema drift. 

uniqtools check file users.csv --key id --required-column email --fail-on-duplicates
uniqtools check compare old.csv new.csv --key id --fail-on-added --fail-on-removed
uniqtools check schema old.csv new.csv --fail-on-schema-change

Checks

Command Purpose
check file Required columns and duplicate key detection in one CSV file.
check compare Added and removed rows by key using uniqdiff comparison semantics.
check schema Added columns, removed columns, type changes, and nullable changes.

Exit codes

  • 0: selected checks passed;
  • 1: selected checks failed;
  • 2: invalid input or usage error.
