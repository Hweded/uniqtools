# UniqTools Documentation Site

This directory contains the static documentation site for GitHub Pages.

The site is intentionally dependency-free:

- plain HTML;
- one CSS file;
- `robots.txt`;
- `sitemap.xml`;
- `llms.txt` and `llms-full.txt` for AI assistant context.

Expected public URL:

```text
https://hweded.github.io/uniqtools/
```

GitHub Pages should deploy the `site/` directory.
